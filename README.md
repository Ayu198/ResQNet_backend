# ResQNet 🚨

ResQNet is an emergency response mobile application designed to improve coordination and reduce response time during critical situations. The application enables users to send emergency alerts, share live locations, and facilitate faster communication during emergencies.

## Features

* User Registration and Authentication
* Secure JWT-based Authentication
* Emergency Alert Management
* Real-Time Location Tracking
* Google Maps Integration
* Firebase Integration for Real-Time Updates
* User Information Management
* Backend API Integration
* Live Data Synchronization
* Mobile-Friendly User Interface

## System Architecture

The application follows a client-server architecture:

1. Android application built using Kotlin.
2. Spring Boot backend exposes REST APIs.
3. JWT authentication secures protected endpoints.
4. MySQL database stores user and emergency-related data.
5. Firebase enables real-time communication and synchronization.
6. Google Maps API provides location tracking and visualization.
